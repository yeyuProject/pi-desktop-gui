# Pi Desktop v0.14.37

- Load tool output and structured diffs when a card is expanded, reducing hidden rendering work when opening long coding conversations. Search results, running tools and errors still reveal their contents automatically.
- Compute file diffs in the background so typing and navigation remain responsive. Switching files cancels the previous preview and prevents stale results from replacing the current file. External edits during calculation keep the stale-preview notice visible until refreshed.
- Move full-file diff expansion and large-patch alignment off the renderer thread. Slow or failed calculations show a clear message with the existing option to open the file in an editor.
- Preserve internal scroll positions when reopening tool cards, full output copying, side-by-side comparisons and hunk follow-ups without replacing the current draft.

## 中文

- 工具输出和结构化差异按需加载，减少打开长编程会话时的隐藏渲染开销。搜索命中、运行中的工具和错误仍会自动显示正文。
- 文件差异改为后台计算，计算期间可以继续输入和切换文件。切换后取消旧预览，防止旧结果覆盖当前文件；计算期间发生的外部修改仍会提示刷新。
- 完整文件差异展开及较大补丁的行对齐也放到后台处理。计算过慢或失败时显示明确提示，并保留在编辑器中查看的入口。
- 再次展开工具卡时恢复内部滚动位置；保留完整输出复制、左右对照和差异段追问，追问时保留已有草稿。
