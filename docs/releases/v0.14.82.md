# Pi Desktop v0.14.82

## Layout jitter

- Fix the whole window shaking continuously at certain window widths. Near the width where the Changes panel switches to overlaying the conversation, the sidebar's resize handle appeared and disappeared on every frame, and with the side conversation open, it also kept switching between drawer and inline. This started in v0.14.78.

Local validation: type checking, lint and formatting passed. 875 unit tests ran: 864 passed and 11 were platform-specific skips. The conversation, workspace and style UI tests passed, with unchanged computed-style baselines for the Classic, Codex and Claude styles. Sweeping window widths from 560 to 1440 px in 2 px steps, with no panel, the side conversation, the Changes panel and both open, the layout no longer switched back and forth; before the fix it did so about 50 times in 0.4 seconds near 1168 px, in both v0.14.80 and v0.14.81.

### 布局抖动

- 修复窗口在某些宽度下整体持续抖动。在变更面板改为浮层的临界宽度附近，侧栏拖拽条每帧出现又消失；打开侧边对话时，它还会在抽屉和并排之间反复切换。此问题从 v0.14.78 开始出现。

本地验证：类型检查、lint、格式检查通过。875 项单测中 864 项通过，11 项按平台跳过。对话、工作区和风格 UI 测试通过，经典、Codex、Claude 风格的计算样式基线不变。窗口宽 560 到 1440 px 按 2 px 逐一检查，无面板、侧边对话、变更面板及两者同时打开时，布局都不再来回切换；修复前 v0.14.80 和 v0.14.81 在 1168 px 附近 0.4 秒内切换约 50 次。
