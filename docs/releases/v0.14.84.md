# Pi Desktop v0.14.84

## Pi updates

- Open Settings → Runtime Environment to check for a newer Pi CLI and install it from the desktop app. Finish any running tasks before starting the update. The app shows progress, then checks the installed version again.

## Long conversations

- While a reply streams, Pi Desktop reuses the turn outline and the Markdown it has already rendered. The composer now grows with its content, and the Changes panel and diff viewer load when opened.
- In a Windows test with 5,000 messages and 200 updates, the 95th percentile of renderer JavaScript time fell from 11.69 ms to 2.76 ms per update. Typing during streaming took 15.5 ms at the 95th percentile from keypress to the next frame.

## 中文

### Pi 更新

- 打开「设置 → 运行环境」即可检查 Pi CLI 新版本并更新。桌面端会显示更新进度，完成后重新读取已安装版本。有任务运行时，等任务结束再更新。

### 长会话

- 回复逐字输出时，桌面端会复用轮次目录和已经渲染的 Markdown。输入框随内容自动调整高度，变更面板和差异预览在打开时加载。
- 在 Windows 上用 5,000 条消息连续更新 200 次，每次更新的渲染 JS 耗时 P95 从 11.69 ms 降至 2.76 ms。回复输出期间打字，从按键到下一帧的 P95 为 15.5 ms。
