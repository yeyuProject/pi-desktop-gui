# Pi Desktop v0.14.66

- Keep loading spinners turning when the system asks to reduce motion, so in-progress states no longer look frozen. Turn jumps and search results scroll instantly instead of smoothly in that mode.
- Stop auto-follow as soon as you scroll up during a streaming reply, even by a few pixels on a trackpad. Scroll back to the bottom to follow again. Thinking blocks behave the same way.
- Keep the jump-to-latest button above the composer when the composer grows with multi-line input, Goal or plan cards.
- Keep the keyboard selection in the model picker, quick switch and `/` command lists when the list scrolls under a resting pointer.
- Pause notifications while hovered or focused, and give notices with an action such as Undo six seconds instead of 3.5.
- Save the reading position when switching chats with the keyboard, not only when the pointer leaves the conversation.
- Fade in the dialog backdrop together with the dialog, add entrance motion to the find bar and jump-to-latest button, and use the same timing for menus, dialogs and hover feedback.

The main JavaScript bundle is 650.50 kB, 0.5 kB above the earlier PF3 target of 650 KB. Close animations for dialogs, menus and notifications are planned separately. Validation: [motion and interaction](https://github.com/yeyuProject/pi-desktop-gui/blob/v0.14.66/docs/testing/motion-interaction.md).

## 中文

- 系统开启「减少动态效果」后，加载图标仍会转动，不再像卡住；轮次跳转和查找结果改为直接跳到位置。
- 流式回复时只要向上滚动，哪怕触控板只滚了几像素，也会停止自动跟随；滚回底部后恢复跟随。思考过程同样如此。
- 输入多行内容，或出现 Goal、计划卡片时，「回到最新」按钮保持在输入框上方，不再被遮住。
- 模型选择、快速切换和 `/` 命令列表滚动时，静止的鼠标不再抢走键盘的选中项。
- 鼠标悬停或键盘聚焦通知时暂停自动关闭；带「撤销」等操作的提示显示 6 秒，原来为 3.5 秒。
- 用键盘切换会话时也会保存阅读位置，不再只在鼠标离开对话区时保存。
- 弹窗遮罩与弹窗一起淡入，查找栏和「回到最新」按钮增加进入动画，菜单、弹窗和悬停反馈使用统一时长。

主 JS 包为 650.50 kB，比原 PF3 的 650 KB 目标多 0.5 kB。弹窗、菜单和通知的关闭动画另行安排。验证记录见[动画与交互测试记录](https://github.com/yeyuProject/pi-desktop-gui/blob/v0.14.66/docs/testing/motion-interaction.md)。
