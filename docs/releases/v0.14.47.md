# Pi Desktop v0.14.47

- Update the verified Pi regression baseline and pinned development dependency from 1.1.0 to 1.4.0. Other recognizable versions remain usable.
- Apply saved built-in tool selections when reconnecting to Pi 1.4.0, so recorded session history cannot re-enable tools disabled in desktop settings; preserve active extension tools.
- Cover the packaging workflow's dependency-result combinations, manual test skipping and cancellation. Tag pushes still require both test jobs to succeed.

## 中文

- 将 Pi 已验证回归基准及开发依赖锁定版本从 1.1.0 更新为 1.4.0，其他可识别版本仍可正常使用。
- 连接 Pi 1.4.0 时应用已保存的内置工具设置，防止会话历史重新启用已取消勾选的工具；保留当前扩展工具。
- 补充打包条件的依赖结果组合、手动跳过测试和取消运行测试；tag push 仍要求两个测试任务都成功。
