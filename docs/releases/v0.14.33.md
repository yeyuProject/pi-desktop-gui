# Pi Desktop v0.14.33

- Coalesce draft writes over 300 ms and store image contents separately. Typing no longer resends unchanged images or broadcasts the entire application state. Sending, switching conversations and shutdown wait for accepted saves.
- Send only changed runtime fields and subscribe to conversation updates separately. Sidebar activity includes background approvals; unrelated panels retain their props during streaming.
- Read history once when switching conversations and restore the saved reading position after history renders. Release background agents after five idle minutes while preserving selected sessions, running work, queues and approval requests.
- Share Escape, focus handling and global shortcuts across dialogs, menus and the workspace panel. Workspace shortcuts use the same tab action as clicking; quick switch focuses its search input.
- Preview desktop appearance changes and save them with the other settings. Warn before discarding unsaved desktop or Pi configuration. Numeric fields validate after editing; resource removal and provider logout ask for confirmation.
- Wait for attachment reads before sending, reject stale sends across session changes, locate repeated tool-search matches precisely, and preserve whitespace in rerun commands.
- Include the nested command ordering and sidebar simplification already merged since v0.14.32. Fix OAuth browser callbacks incorrectly cancelling a successful login.

Draft storage now uses index format 2 and a `draft-images` directory. Older releases open the new index read-only. Pre-upgrade indexes and existing image files are retained for recovery; image files are not automatically removed while backups may reference them.

## 中文

- 草稿写盘在 300 毫秒内合并，图片内容单独保存。输入文字不再重复发送未变化的图片，也不再触发完整应用状态广播；发送、切换会话和退出会等待已接收的保存。
- 运行状态只发送变化字段，界面按会话订阅更新；侧栏显示后台审批，流式输出时无关面板保持稳定。
- 切换会话只读取一次历史，并在历史渲染后恢复阅读位置。后台会话空闲五分钟后回收进程和缓存，保留当前会话、运行中的任务、队列和待审批操作。
- 统一弹窗、菜单与工作区面板的 Esc 和焦点管理。快捷键切页与点击页签使用同一动作，快速切换打开后可直接输入。
- 桌面外观先预览，与其他设置一起保存；关闭未保存的桌面或 Pi 配置时给予提示。数字输入完成后再校验范围，移除资源包和退出供应商登录需确认。
- 附件读取完成前禁止发送；切换会话时拦截旧输入框的发送请求；修复工具参数重复搜索定位和带前导空白的命令重跑。
- 一并发布此前已合并的嵌套命令显示顺序和侧栏图标调整，修复 OAuth 浏览器回调成功却被误取消的问题。

草稿存储升级为索引格式 2，图片位于 `draft-images` 目录。旧版应用会以只读方式打开新索引。升级前索引及已有图片文件保留用于恢复；图片可能仍被备份引用，因此暂不自动删除。
