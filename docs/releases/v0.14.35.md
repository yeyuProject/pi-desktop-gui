# Pi Desktop v0.14.35

- Fix file checkpoint failures when a Git repository subdirectory is opened as the project. Snapshot storage and file hashing now resolve paths from the opened project before passing them to Git.
- Prevent same-named files in the repository root from being read in place of project files, so tool changes are correctly identified for undo.

## 中文

- 修复将 Git 仓库子目录作为项目打开时，文件存在却提示“无法保存文件检查点”的问题。保存快照和校验文件时，先按打开的项目目录解析文件路径，再交给 Git。
- 避免误读仓库根目录下的同名文件，确保正确识别工具修改并支持撤销。
