# Pi Desktop v0.14.28

本版修复 macOS 安装包缺少完整应用签名的问题。

- macOS 的 Intel 和 Apple Silicon 构建都显式使用 ad-hoc 签名，覆盖应用、资源与内嵌组件，避免仅保留 Electron 原始可执行文件的签名。
- 目录包和正式安装包构建完成后，必须通过 `codesign --verify --deep --strict`；即使意外关闭签名，完整性校验仍会阻止发布。
- 本次签名修复不等同于 Apple Developer ID 签名或公证，首次下载仍可能受到 Gatekeeper 限制，中英文安装说明同步说明这一范围。
- macOS 会收录项目目录中的可运行 `.app`。测试包和回退备份应压缩保存；安装完成后弹出 DMG，并从 `/Applications/Pi Desktop.app` 启动，避免重复图标和误开旧版。

发布执行三平台测试、Windows/Linux 升级回归，以及安装包和更新元数据校验。此次本机重复图标清理不修改会话、模型配置或历史用量。
