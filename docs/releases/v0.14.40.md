# Pi Desktop v0.14.40

- Require a main-process confirmation before resource-package installation or updates. Show the source and affected scopes, explain installation-script execution, and preserve the input when cancelled. Package updates correctly cover Pi's configured scopes without an unsupported `--local` flag.
- Preserve files when undoing a case-only filename rename. Report paths and subtrees excluded by snapshot limits, protect unrecorded paths in older checkpoints, and explain partial undo failures while refreshing the workspace.
- Keep original queued input, file references, collapsed pastes and images through stop/crash recovery, including prompt templates. Forked drafts no longer contain expanded project-file contents.
- Read UTF-8 BOM configuration and offer an editable repair document for malformed JSON, with its path, an explicit raw-content warning and an original-file backup.
- Avoid full transcript reconciliation after ordinary turns while retaining it for compaction, navigation, recovery and incomplete streams. Cache snapshot hashes for up to eight alternating chats.
- Improve credential redaction, reject files when opening a working directory, keep missing Bash visible in readiness checks, set Windows Python output to UTF-8, and clean up terminal handoff locks on normal exit. Explain that detached background services may require manual shutdown.
- Add ESLint, CI formatting checks, cancellation of superseded branch/PR checks, and consistent LF text files. Keep lint tooling separate from application builds and installers.

## Scope and limits / 范围与限制

Tracked child processes are terminated by the existing process-tree cleanup. Services that escape tracking may need to be stopped manually. UTF-8 settings help Python subprocesses; third-party programs that force another encoding still need their own output configuration. A case change in a parent directory is rejected before undo writes so unrelated sibling paths are not moved implicitly. Internationalization is outside this release.

已跟踪的子进程仍由进程树清理处理；脱离跟踪的服务可能需要手动停止。UTF-8 设置适用于 Python 子进程，强制使用其他编码的第三方程序仍需配置其输出。仅父目录改大小写时，撤销会在写入前拒绝并提示手动恢复，避免隐式移动未选择的其他路径。本版不包含国际化。
