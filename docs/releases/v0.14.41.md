# Pi Desktop v0.14.41

- Reuse unchanged file hashes when refreshing changes for the current run. Each refresh still checks file metadata and snapshot exclusions, hashes changed or new files, and drops deleted paths. The cache is limited to eight projects; undo retains its final fresh scan.
- Reuse a successfully loaded model catalog when reopening the model picker in a disconnected chat. Add an explicit refresh button and invalidate cached catalogs after relevant configuration changes. Failed or outdated catalog reads remain retryable.

## 中文

- 刷新“本轮变更”时复用未改动文件的哈希，减少重复读取整个项目。每次仍检查文件元数据及快照排除范围，只重新哈希新增或变化的文件，并移除已删除路径；最多缓存八个项目，撤销前仍执行最终扫描。
- 未连接会话再次打开模型选择器时，复用已成功读取的模型列表；增加“刷新模型列表”按钮，相关配置变化后自动失效。读取失败或读取期间配置已变化时，允许重新获取。
