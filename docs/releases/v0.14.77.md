# Pi Desktop v0.14.77

## Side conversation fixes

- Clear a side question from the input as soon as it is sent. Previously the question stayed in the locked input until the whole answer finished, so it appeared both there and in the conversation. A question that cannot be sent is put back.
- Keep the input usable while a side answer streams, so the next question can be written; it can be sent once the current answer finishes.
- Match the main composer: a rounded input that grows with its text, the context range and a round send/stop button inside it, and the model name in the header. Questions appear as right-aligned bubbles, and an empty answer shows "Thinking…" until the first words arrive.
- Follow a streaming answer only while you are at the bottom, so reading earlier messages is no longer interrupted.

Local validation: type checking, lint and formatting passed, and the 35 side conversation and session agent unit tests passed. The chat UI test passed the side conversation checks, including a new check that the input is empty while an answer streams. That test failed at different, unrelated steps between runs on this machine, also without these changes. Light and dark screenshots were checked.

## 中文

### 侧边对话修复

- 侧边问题发送后立即从输入框清除。此前问题会留在被锁定的输入框中直到回答结束，因此同时出现在输入框和对话中。无法发送的问题会恢复到输入框。
- 回答进行中输入框仍可编辑，可以先写下一个问题，当前回答结束后再发送。
- 与主输入框一致：圆角输入框随内容增高，上下文范围和圆形发送/停止按钮放在框内，模型名移到标题栏。提问显示为右侧气泡；回答首字到达前显示“正在思考…”。
- 只有停在底部时才跟随流式回答滚动，翻看之前的内容不再被打断。

本地验证：类型检查、lint、格式检查通过，侧边对话与会话代理的 35 项单测通过。对话 UI 测试的侧边对话部分通过，并新增检查：回答进行中输入框为空。该测试在本机多次运行中会在不同的无关步骤失败，未改动的代码同样如此。已检查白天和夜晚截图。
