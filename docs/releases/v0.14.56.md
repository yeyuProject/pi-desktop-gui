# Pi Desktop v0.14.56

- Add a Codex appearance alongside Pi Classic, with Day, Night and Follow System modes. Preview changes in settings, discard them or save them across restarts; saved colors also update the native window and title bar.
- Use neutral surfaces, black or white primary buttons, blue links, green completion indicators and right-aligned question bubbles. Keep existing layouts, accessible speaker names and keyboard shortcuts.
- Preserve Pi Classic's existing light and dark styles, and fix dark syntax and ANSI colors when following the system appearance. Codex text, syntax and focus colors pass the specified contrast checks.
- Verify long questions, files, images, quotes, skills, wide code blocks, Goal cards, approvals, side conversations, model pickers and the turn outline in both Codex modes.
- Includes the v0.14.55 Goal composer: start and edit objectives in the ordinary input box, attach files/images/quotes, and save Goal mode and usage limits per conversation.
