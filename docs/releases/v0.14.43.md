# Pi Desktop v0.14.43

- Add **默认展开思考过程** under Settings → Appearance and editor. The preference applies to current and historical thinking, persists across restarts, and keeps thinking expanded after a reply finishes. Manual folding, collapse-all and search remain available; the default remains collapsed.
- Replace the app icon with the selected three-character Pi illustration across Windows, macOS and Linux, and update the README icon previews and character attribution. Reference artwork provenance and non-commercial attribution conditions remain documented in `build/icon-source-v2.prompt.txt`.
