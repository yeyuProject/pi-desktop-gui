# Pi Desktop v0.14.87

## Turn outline

- The turn outline beside the conversation is now a compact rail: one short tick per turn, clear of the scrollbar, with the current turn highlighted. A shaded block shows which turns are on screen, and when you scroll to the bottom the last turn is current.
- Hover the rail to magnify the ticks near the pointer and open the turn list next to it. Ticks mark turns with changes, failures and the running turn. Filters with a count of zero are hidden.
- Opening, switching and new turns use short transitions, which turn off when the system asks for reduced motion.

## Corners

- Every corner now uses one set of sizes. The default style is rounder, and corners inside the input box and dialogs line up with their frame. The Codex and Claude styles keep their input box, message bubble and code block shapes, and the Claude send button.
- An expanded tool card is one panel. Copy output appears at its top right when you hover or focus it, and View file stays visible.

## Glass

- In Settings → Appearance and editor, the default style can use a Glass material: the sidebar, title bar, header, input box and menus become frosted and translucent in the Light, Dark and System themes.
- Pi Desktop shows solid surfaces instead when graphics acceleration is off, when the system asks for reduced transparency, or on battery power. You can turn off the battery rule. In a Windows test with 5,000 messages, glass used about the same CPU as solid while scrolling and streaming.

## 中文

### 轮次目录

- 对话右侧的轮次目录改为一条紧凑的刻度轨：每轮一根短刻度，不再压在滚动条上，当前轮高亮显示。浅色块标出这一屏里能看到的轮次，滚到底部时当前轮就是最后一轮。
- 鼠标移到刻度轨上，附近的刻度会放大，旁边弹出轮次列表。刻度会标出有修改、有失败和正在运行的轮次。筛选按钮数量为 0 时不显示。
- 展开、切换和新增轮次都有简短的过渡动画；系统开启「减少动态效果」时不播放。

### 圆角

- 所有圆角统一为一组尺寸。默认风格整体更圆润，输入框和弹窗里的控件与外框圆角协调。Codex 和 Claude 风格保留原来的输入框、消息气泡和代码块形状，Claude 的发送按钮也不变。
- 展开的工具卡片合为一个整体。鼠标悬停或键盘聚焦时，右上角出现「复制输出」；「查看文件」始终显示。

### 玻璃材质

- 在「设置 → 外观与编辑器」中，默认风格可以选择「玻璃」材质：在浅色、深色和跟随系统主题下，侧栏、标题栏、顶栏、输入框和菜单呈半透明磨砂效果。
- 未启用显卡加速、系统开启「降低透明度」或使用电池供电时，桌面端会自动改用实色；电池这一条可以关闭。在 Windows 上用 5,000 条消息测试，滚动和流式输出时，玻璃材质的 CPU 占用与实色基本相同。
