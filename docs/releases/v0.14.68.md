# v0.14.68

## 改进

- 侧栏新增会话「移动到…」菜单与跨项目拖动入口，支持移入项目或转为独立对话。移动历史会话时显示影响说明，通过 Pi 原生会话复制接口更新实际工作目录，并保留历史及会话偏好。
- 移动时检查任务、待确认事项、侧边回答、终端占用及源文件状态；持久化采用暂存提交，避免在保存失败时暴露未提交的归属。
- 应用内弹窗支持从标题栏拖动、双击居中及边界约束，交互按钮不触发拖动。
- 调整模型浮层中的推理级别布局：独立标题、等宽选项、更清晰的选中态，并支持方向键切换。
