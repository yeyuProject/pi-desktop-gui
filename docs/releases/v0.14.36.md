# Pi Desktop v0.14.36

- Speed up large Pi RPC responses and reuse search results and tool diff statistics in long conversations. History jumps and search navigation use 80-message pages, with controls to browse adjacent pages or return to the latest messages.
- Show the window before login-shell PATH discovery and snapshot cleanup finish. At startup, check draft image references and file sizes; verify image contents when their conversation is opened. Failed image validation preserves the files and pauses sending and saving.
- Keep typing and elapsed-time updates separate from the conversation. Stop elapsed timers after a run finishes, and avoid duplicate Git status checks and unchanged checkpoint updates when the window regains focus.
- Reuse unchanged file hashes at command boundaries. Coalesce state saves during a run while retaining immediate saves at completion and other durability boundaries.
- Clean up the active session's checkpoints and account for changed storage incrementally. Periodic full scans and immediate capacity checks retain the 20-turn, seven-day and 200 MiB limits, with restoration covered after old checkpoints are removed.
- Keep completed Markdown sections mounted when streaming ends, preserving code-block controls and avoiding a full reparse for ordinary long replies. Reference documents and single oversized blocks still receive complete final Markdown rendering.

## 中文

- 加快大型 Pi RPC 响应的解析，长会话查找和工具差异统计复用已有结果。历史跳转与查找按每页 80 条消息显示，可前后翻页或回到最新消息。
- 窗口先显示，再完成登录 shell PATH 获取和快照清理。启动时只检查草稿图片索引及文件大小，打开对应会话时再校验图片内容；校验失败会保留原文件并暂停发送和保存。
- 输入和耗时更新不再带动对话区重渲染，运行结束后停止计时。窗口重新获得焦点时，合并重复的 Git 状态查询，不重复更新内容未变的检查点列表。
- 命令执行前后复用未变化文件的哈希。运行中的状态保存合并写入，任务结束等必须落盘的时点仍立即保存。
- 每轮只清理当前会话的检查点，并按变化的文件增量统计占用；定期核对全库，超出容量时立即清理。继续执行每会话 20 轮、保留 7 天和总量 200 MiB 的限制，删除早期检查点后仍可恢复后续检查点。
- 流式回复结束时保留已完成的 Markdown 段落和代码块操作状态，普通长回复不再整条重解析；含跨段引用的文档和单个超长块仍完成完整的最终排版。
