# Pi Desktop v0.14.31

- Enable macOS in-app updates: download the ZIP matching the running architecture, verify SHA-512, bundle identity, version and strict code-signature integrity, then offer restart or installation on normal quit.
- Save drafts and session state and wait for clean process exit before replacing the running app. A same-volume atomic bundle exchange preserves the previous app in a hidden directory; a failed final signature check exchanges it back. The next successful upgrade retires older completed backups.
- Refuse stale installers when another copy has replaced the application. Cancel installation on shutdown, unreadable packages, invalid signatures or unwritable/translocated/disk-image installations. Manual release downloads remain available.
- Add packaged Mac upgrade acceptance, including automatic reopen, normal-quit installation, data preservation, busy-task protection, damaged downloads, changed bundles and rollback. Mac CI runs this through the existing native desktop acceptance command.

Mac versions through v0.14.30 cannot install this update automatically: install v0.14.31 once from the full ZIP or DMG, then subsequent releases can update in-app. The project still uses ad-hoc signing, without Apple Developer ID or notarization; integrity checks do not authenticate a publisher independently of the trusted GitHub release channel. No Gatekeeper or quarantine protections are disabled by the updater.

## 中文

- macOS 支持应用内升级：下载匹配当前架构的 ZIP，校验 SHA-512、应用标识、版本及签名完整性后，可立即重启或在正常退出时安装。
- 升级前保存草稿和会话，等待原进程正常退出后才替换应用。使用同盘原子交换，在隐藏目录保留旧版；最终签名校验失败时交换回原版，下一次成功升级后清理更早的备份。
- 检测到应用已被其他更新替换时取消旧安装器；系统关机、更新包无法读取、签名无效，或应用位于不可写目录、磁盘映像、App Translocation 临时目录时不覆盖安装。继续保留手动下载入口。
- 新增打包版 Mac 升级回归，覆盖自动重开、退出安装、数据保留、任务保护、下载损坏、应用变化和失败回退，纳入现有 Mac 桌面 CI 验收。

v0.14.30 及更早的 Mac 版本需要先从完整 ZIP 或 DMG 安装一次 v0.14.31，后续才能在应用内升级。当前仍采用 ad-hoc 签名，没有 Apple Developer ID 或公证；完整性校验不能独立于受信任的 GitHub 发布渠道认证发布者身份。更新器不会关闭 Gatekeeper 或解除隔离属性。
