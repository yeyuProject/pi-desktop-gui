# Pi Desktop v0.14.86

## Narrow sidebar

- When the sidebar is narrow or the font size is larger, the header shows only the π mark instead of a cut-off name, and New session stays on one line. The shortcut hint moves into its tooltip.
- Project names use the whole row. The + and ⋯ buttons appear when you hover a project, move to it with Tab, or open its menu. At the default width and font size, they stay visible as before.

## 中文

### 窄侧栏

- 侧栏较窄或字号较大时，顶部只显示 π 标志，不再显示被截断的名称；「新建会话」保持一行，快捷键改在鼠标悬停时提示。
- 项目名占满整行。鼠标悬停在项目上、用 Tab 键移到项目上或打开项目菜单时，才显示「+」和「⋯」按钮。默认宽度和字号下，按钮仍和以前一样一直显示。
