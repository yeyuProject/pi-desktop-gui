# Pi Desktop v0.14.60

- Enforce the 128 MiB limit for every Pi JSONL record using raw bytes, including its final fragment. Discard an oversized record through its newline before accepting the next record.
- Keep inherited desktop environment variables from changing test behavior or redirecting test app data. Checkpoint fixtures explicitly enable their own checkpoint flow.
- Share Electron test startup, page error collection and cleanup across the UI scripts, including cleanup after the application has already crashed or exited.
- Separate session, draft, agent and settings IPC handlers, and define each IPC method's storage, update and workspace rules in one typed table. Move operation queues, extension dialogs and runtime publication into dedicated modules while preserving the existing behavior.

## 中文

- Pi JSONL 每条记录统一按原始字节检查 128 MiB 上限，包含换行的最后一块也在解析前检查。超限后丢弃整条记录，再读取下一条。
- 测试不再被宿主的桌面环境变量影响，也不会继承宿主的数据目录；检查点测试显式开启自己的检查点流程。
- UI 脚本共用 Electron 启动、页面错误收集和退出清理代码，应用已经崩溃或退出时也能正确完成清理。
- 拆分会话、草稿、Agent 和设置 IPC 处理，集中声明各接口的存储、更新和目录保护规则；操作队列、扩展弹窗和状态发布由独立模块管理，保持现有行为。
