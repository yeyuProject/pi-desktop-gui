# Pi Desktop v0.14.49

- Add a built-in Goal extension and a visible Goal button beside the message input. The current working model continues toward the objective and must provide completion evidence; pause, resume, clear, usage limits and restart recovery stay within the session.
- Redesign the conversation turn outline with fixed ticks, cleaned titles and skill labels, nonzero change counts, failure and running states, and filters for conversations with ten or more turns.
- Add Alt/Option + Up/Down turn navigation, Escape to close the outline, and a one-second jump highlight. Preserve cursor movement in nonempty text inputs and keep rapid navigation and short final turns aligned with the requested turn.
- Keep long-conversation rendering bounded to 58 outline rows plus two filter buttons, and verify all five themes meet 4.5:1 text contrast.
- Show recognized Pi versions without verified/unverified badges while retaining compatibility classification in diagnostics.

## 中文

- 新增内置 Goal 扩展与输入框旁的 Goal 按钮。沿用当前工作模型持续推进目标，完成时必须提交证据；支持暂停、继续、清除、用量限制及重启恢复。
- 重做对话轮次目录：刻度位置固定，清洗标题并显示技能标签，只展示非零增删，区分失败和运行状态，十轮以上可按修改或失败筛选。
- 增加 Alt/Option + 上下方向键切换轮次、Esc 收起目录与一秒定位高亮。文本输入框非空时保留系统光标行为，修复快速连续跳转和末尾短轮次的定位状态。
- 长对话最多渲染 58 个目录行与 2 个筛选按钮，五套主题的文字对比度均达到 4.5:1。
- 可识别的 Pi 版本只显示版本号，不再显示“已验证 / 未验证”标签；诊断信息继续保留兼容性分类。

Version v0.14.48 was not published. This release also updates the earlier turn-navigation regression to use accessible labels and virtual-list navigation.

v0.14.48 未公开发布。本版同时更新旧轮次导航回归测试，使用无障碍标签及虚拟列表导航定位目标轮次。
