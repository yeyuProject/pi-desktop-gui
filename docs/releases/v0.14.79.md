# Pi Desktop v0.14.79

## File menu

- Right-click a file or folder in the Changes list, the Files tree or file search results to open it with the default app or show it in its folder.
- Opening follows the same rules as local links in replies. Documents, images, audio, video and plain folders open with the system default app. Scripts, apps, packages and unknown types are never launched: they open in the configured code editor, or are shown in their folder with an explanation. Paths outside the project or inside `.git` are refused.
- The menu also opens with Shift+F10 or the context-menu key, moves with the arrow keys, and closes with Esc, a click outside, scrolling or resizing.

Local validation: type checking, lint and formatting passed. 874 unit tests ran: 863 passed and 11 were platform-specific skips. A new test covers the open rules for project files, including a file named with a literal `%20`. In a built app, the menu appeared at the pointer in the Changes list and the Files tree and worked with the keyboard. Opening real files was not exercised, because it would launch windows on the test machine.

## 中文

### 文件右键菜单

- 在“变更”列表、“文件”树和文件搜索结果中右键文件或文件夹，可以用默认程序打开，或在文件夹中显示。
- 打开规则与回复中的本地链接相同：文档、图片、音视频和普通文件夹用系统默认程序打开；脚本、应用、安装包和未知类型的文件不会被运行，而是用已设置的代码编辑器打开，或在文件夹中显示并说明原因。项目以外和 `.git` 内的路径会被拒绝。
- 也可以用 Shift+F10 或菜单键打开菜单，方向键切换，Esc、点击外部、滚动或调整窗口大小时关闭。

本地验证：类型检查、lint、格式检查通过。874 项单测中 863 项通过，11 项按平台跳过。新增测试覆盖项目文件的打开规则，包括名称中含 `%20` 的文件。在构建的应用中，“变更”列表和“文件”树里菜单出现在指针位置，键盘操作正常。未实际打开文件，以免在测试机上弹出窗口。
