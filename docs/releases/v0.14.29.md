# Pi Desktop v0.14.29

- Choose black-and-white (the default), green, blue or violet accents independently of the light, dark or system theme. Accent changes apply immediately and are saved.
- Keep project and conversation menus visible and clickable at the bottom of the sidebar. Menus reposition within the window and close when scrolling or resizing.
- Use the native editing context menu in text fields for undo, redo, cut, copy, paste and select all.
- Read the model catalog even if a saved conversation's transcript has disappeared. The disposable probe directory is cleaned even when the file disappears during copying; other IO errors are still reported.
- Report a successful recycle-bin operation only after the transcript was actually moved. Empty conversations and entries with missing transcripts have distinct deletion notices. Failed filesystem or trash operations leave the conversation entry in place.
- Preserve the original contributions from abnormalboy/chming in PR #20 and PR #21, with additional race/error regressions and a TypeScript test correction.

These changes do not establish that the selected-conversation UI failure reported in issue #13 is fully resolved; the reporter's Windows scenario still needs separate verification.
