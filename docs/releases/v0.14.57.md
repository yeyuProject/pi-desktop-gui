# Pi Desktop v0.14.57

- Add Claude appearance with Light, Dark and Follow System modes. Preview or discard changes, save them across restarts, and keep the native window and title bar in sync.
- Use warm surfaces, coral primary buttons, blue links and right-aligned question bubbles. Assistant replies use system serif fonts with Chinese fallbacks; code stays monospaced and reply text follows the 100–200% font setting.
- Preserve Pi Classic and Codex appearances against their existing computed-style baselines. Centralize style labels, supported themes and native palettes so settings and validation use the same registry.
- Cover contrast, keyboard focus, accessible speaker names, long questions, attachments, quotes, wide code blocks, Goal cards, approvals and side conversations in both new modes.
