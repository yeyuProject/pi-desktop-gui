# Pi Desktop v0.14.62

- The conversation footer now updates token and context estimates while the assistant is generating. Estimates are marked and may change when the provider reports actual usage.
- Session usage refreshes after each model response, including during multi-step tasks. Estimated streaming values are not saved as confirmed session usage; costs update when Pi reports them.
- The README demo now follows the same estimate-and-reconcile behavior and uses distinct examples for current context and cumulative usage.

## 中文

- 助手生成时，对话底部实时更新 Token 和上下文估算，并标注“约”；服务商返回用量后，数字可能上调或回落。
- 多步骤任务中，每次模型回复结束都会刷新会话用量。流式估算不会写入已确认的会话统计，费用在 Pi 返回后更新。
- README 演示同步展示估算和校准，并分别示例当前上下文与会话累计用量。
