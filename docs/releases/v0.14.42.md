# Pi Desktop v0.14.42

- Show average output TPS below completed assistant replies using Pi's output token count and response duration. The duration includes response waiting time and excludes tool execution; replies without valid measurements do not show a speed.
- Keep model refresh available beside search in both connected and disconnected chats. Connected refreshes reload the live model registry, preserve the conversation and current selection, and show loading and retryable errors.
- Cancel connected provider refreshes after 15 seconds and release the session operation queue, so a slow provider cannot block the conversation for the bridge's ten-minute timeout.

## 中文

- 完整助手回复下方显示平均输出 TPS，直接使用 Pi 的输出 Token 数和响应耗时；包含等待响应时间，不包含工具执行时间，缺少有效统计数据时不显示速度。
- 已连接与未连接会话都可在模型搜索旁刷新列表。已连接会话会重新加载实际模型目录，保留当前会话和模型选择，并显示刷新状态及可重试的错误提示。
- 已连接会话的供应商模型刷新超过 15 秒自动取消并释放操作队列，避免慢供应商让会话一直等到原有桥接请求的十分钟超时。
