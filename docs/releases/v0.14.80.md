# Pi Desktop v0.14.80

## Model picker layout

- Keep models stacked vertically within each provider. Opening the picker with a later model selected no longer scrolls the list sideways or leaves large blank areas above the visible models.
- Allow the footer hint to wrap so the connection settings button remains visible.

- 底部提示文字可以正常换行，连接设置按钮不再被挤出弹窗。
