# Pi Desktop v0.14.30

- Add sepia, soft green and navy background themes alongside light, dark and system appearance. Window backgrounds, sidebars, panels, text and native title bars follow the selected palette; changes apply immediately and persist.
- Replace the separate accent-color setting with background themes. Existing accent settings are ignored; buttons and selected items use the light or dark base accent.
- Improve Chinese reading text and suggestion descriptions with the fuller system font face, clearer contrast and spacing. Code and JSON remain monospaced.
- Clear completed update receipts on the next launch so a successful update no longer keeps reporting an unconfirmed installation. Pending or failed attempts for newer versions remain visible.
- Strengthen quit and upgrade acceptance tests by checking the expected window close together with a clean process exit, including cases where the renderer closes before acknowledging the quit action.

This release includes PR #24, #25 and #26. The existing macOS signing strategy is retained; PR #23 is not included.
