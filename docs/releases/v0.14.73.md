# Pi Desktop v0.14.73

## Team UI fixes

- Make pending member approvals easier to act on: show the member and requested operation, and jump directly to the matching approval from the team strip.
- Improve team cards, role labels, task previews, progress text, elapsed time and token units. Keep Markdown reports intact when expanding long reports, and show a readable report headline.
- Preserve manual sidebar group collapse, list members in dispatch order, and announce only changed member statuses to screen readers.
- Improve the Team toggle and approval layout; fix unreadable undo actions in success toasts and clipped pending badges in the sidebar.

Tests were skipped for this release at the maintainer's request. Three-platform packaging, update metadata validation and independent update signing remain required.
