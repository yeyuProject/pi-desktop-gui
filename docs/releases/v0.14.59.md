# Pi Desktop v0.14.59

- Show the signed installer size before an update is downloaded. During download, show the transferred amount, recent speed and estimated time remaining in Settings and the release dialog.
- Explain the transfer size for incremental updates, show when the network stops responding, and show verification or macOS preparation after download. The sidebar keeps a compact status, while screen readers hear phase changes instead of every progress update.
- Refresh update progress without rerendering the conversation, composer or session sidebar. Downloads, retries, installation confirmation and restart follow the existing update rules.
- Simplify the Goal input prompt and redesign the budget popup. A limited budget shows the estimated number of requests when usage history is available; the estimate's details remain accessible through the information hint.
