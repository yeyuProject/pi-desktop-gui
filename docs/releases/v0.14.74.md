# Pi Desktop v0.14.74

## Team settings layout

- Align Settings → Team with the other settings pages: each option has its own label row and a full-width select, with its explanation shown beside the label instead of crowding the controls on one line.
- Show units in option text (for example "3 个成员" and "1m tokens") and mark each changed option as unsaved.
- Keep a saved member default model visible as "currently unavailable" when it is not in the model list, instead of silently showing "Follow lead". Fall back to the model id when a model has no display name.

## Team fix

- Stopping the lead right after a member finished no longer reports that member as stopped. The lead's team result now keeps the member completed, matching the sidebar and the member session.

Local validation: build, type checking, lint and formatting passed; 869 unit tests ran with 867 passing and 2 platform-specific skips, including a new regression test for stopping the lead while a completed member is still saving. The real Pi team integration test passed five consecutive runs, the team UI end-to-end test passed, and the Team settings page was checked in all three UI styles in light and dark themes. The release workflow runs the full test suite and three-platform packaging.

本地验证：构建、类型检查、lint、格式检查通过；869 项单测中 867 项通过，2 项按平台跳过，其中新增“成员完成后仍在保存时停止负责人”的回归测试。真实 Pi 团队集成测试连续 5 次通过，团队 UI 端到端测试通过，团队设置页在三种界面风格的浅色和深色主题下均已核对。发布工作流运行完整测试和三平台打包。
