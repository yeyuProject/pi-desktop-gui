# Pi Desktop v0.14.71

## Improvements

- Group new-version status, download progress, restart options, actions and release notes into one card in Settings → About & Updates.
- A downloaded update clearly shows its version and that a restart applies it. Place the automatic-restart choice above the restart button, keep the busy-state explanation nearby and remove the redundant download-page action once the update is ready.
- Share status presentation and restart hints with the update dialog. Download, installation, approval and draft-saving behavior are unchanged.

Local validation: build, lint and formatting passed; 848 unit tests passed with 2 platform-specific skips. The update UI regression passed, including the settings card layout, download states, manual-install fallbacks, task/approval restart restrictions and saving the latest draft before restart. Cross-platform checks and packaging run in the release workflow.
