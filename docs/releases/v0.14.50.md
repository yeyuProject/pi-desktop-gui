# Pi Desktop v0.14.50

- Collapse expanded skill bodies and long questions, reveal search matches automatically, and keep saved expansion states. Turn navigation now leaves the question end and reply start visible; copy a turn's last text reply directly from the message footer or turn outline.
- Quote selected conversation text, code, thinking, and tool output in the draft. Quotes keep their source links, survive restarts and edit/resend, and return to the original passage when clicked.
- Ask separate questions in Side Chat while the main task runs. Choose selected quotes, context through a reply, or the completed conversation; side requests have no tools and never append to the main Pi session.
- Keep side history and usage separately, stop side replies independently, quote answers back into the main draft, or prepare a new chat without sending it. Side Chat remembers its width and becomes a drawer below 900 px.
- Keep long-conversation rendering bounded: 5,000 messages render an 80-message page, and the turn outline stays within 60 buttons, including hovered and focused copy controls.

## 中文

- 技能正文和长提问默认折叠，查找命中时自动展开，并保存展开状态。轮次跳转后可同时看到提问末尾和回复开头；可在回复底部或轮次目录直接复制本轮最后一条正文回复。
- 选中对话文字、代码、思考过程或工具输出后，可引用到草稿。引用保留出处链接，重启和编辑重发后仍能恢复，点击出处可返回原文。
- 新增“侧边对话”，主任务运行时也能单独提问。支持仅引用内容、到某条回复和整个已完成会话三种上下文范围；侧边请求没有工具，不写入主 Pi 会话。
- 侧边历史与用量单独保存，可独立停止回答、把回答引用回主草稿，或准备新会话继续提问而不自动发送。面板宽度可保存，小于 900 px 时显示为抽屉。
- 保留长对话的渲染限制：5,000 条消息只渲染 80 条消息的一页，轮次目录连同悬停和聚焦的复制控件最多 60 个按钮。
