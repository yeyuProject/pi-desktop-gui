# Pi Desktop v0.14.34

- Reuse completed Markdown sections during streaming and render a bounded turn outline with keyboard navigation. Very long unfinished blocks display their source until the reply finishes, then receive full Markdown formatting.
- Reuse serialized user messages, including images, while the assistant streams. Load saved draft images for the selected chat and omit their bodies from application state broadcasts; keep hash verification and durable saves.
- Flush pending draft writes immediately before sending or switching conversations, avoiding the 300 ms typing debounce while still waiting for disk completion.
- Cache history and searchable text within explicit budgets, invalidate changed files, yield during long parsing, and cancel obsolete searches. Avoid loading a second transcript when the live session already has it.
- Open the workspace before Pi environment checks complete. Preserve image attachments when typing, selecting new images or receiving state updates during restoration.
- Finish closing a cancelled Pi startup before treating its rejected abort request as a stop failure, so quitting during connection can complete normally.

See the [performance validation](../testing/performance-v0.14.34.md) for measured results, reproduction commands and remaining limits. Draft index format remains 2.

## 中文

- 流式输出复用已完成的 Markdown 段落；轮次导航按需渲染，支持方向键和 Home/End。特别长的未完成块暂时显示原文，回复结束后完整排版。
- 助手回复时复用未变化的用户消息序列化结果，包括图片。草稿图片随当前会话读取，状态广播不再携带图片正文；保留哈希验证与落盘保障。
- 发送、切换会话前立即写入待保存草稿，省去输入时的 300 ms 合并等待，仍然等待磁盘保存成功。
- 历史与搜索缓存设定容量上限，文件变化时失效；长解析分段让出事件循环，新查询取消旧搜索。运行状态已包含完整历史时，界面不再读取另一份副本。
- 工作台先打开，Pi 环境检测随后完成。图片恢复期间继续输入、添加图片或接收状态更新，都保留已有附件。
- 取消 Pi 启动后，先确认旧进程关闭，再处理被拒绝的停止请求，避免连接期间退出卡在错误提示。

实测数据、复现命令与剩余限制见[性能验证记录](../testing/performance-v0.14.34.md)。草稿索引格式保持为 2。
