# Pi Desktop v0.14.55

- Start Goals from the existing composer with files, images, pasted snippets and conversation quotes. The first message uses your original text and displays a persistent Goal badge.
- Set usage limits in a compact popover. Goal mode and budget persist per conversation without connecting to Pi; slash-command previews and Escape keep the objective and attachments intact.
- Edit objectives inline with a separate saved buffer. Saving or cancelling restores the ordinary draft; stale revisions are rejected without discarding text.
- Reuse ordinary send validation and storage barriers, send the initial message once, and preserve drafts when validation fails or replacement is cancelled.
- Separate starting a new Goal from viewing the previous result, and prevent queued objective edits from causing extra requests after completion.

## 中文

- 在现有输入框直接开始 Goal，文件、图片、粘贴片段和对话引用随首条消息一起发送。首条消息保留原文，并显示可在历史中恢复的 Goal 标记。
- 用量上限改为小浮层；Goal 模式和预算随会话保存，写目标无需连接 Pi。命令预览与 Esc 退出保留实际目标和附件。
- 编辑目标改为输入框内的独立草稿，保存或取消后恢复原草稿；过期版本拒绝保存且保留文字。
- 复用普通发送的校验和落盘流程，首条消息只发送一次；验证失败或取消替换时保留草稿。
- 已完成 Goal 的新建入口与查看上个结果分开；修复连续编辑提示在完成后可能触发额外请求的问题。
