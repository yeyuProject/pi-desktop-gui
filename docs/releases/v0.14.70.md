# Pi Desktop v0.14.70

## Fixes and maintenance

- Validate fields consumed from Pi message, streaming, tool, queue and session-entry events before they update desktop state. Malformed known events report a protocol error instead of reaching the conversation; unknown event types and additional fields remain compatible.
- Preserve existing fallbacks for optional fields, custom message roles and tool errors. Notification retention, update-on-quit policy, approval and stop behavior are unchanged.
- Remove unused component parameters and unreferenced helpers. Correct PRD test-file references and distinguish the current Pi regression baseline from historical validation records.

Local validation: build, lint and formatting passed; 848 unit tests passed with 2 platform-specific skips; real Pi integration, Goal and feature suites passed against isolated local model fixtures. Temporary probes covered 26 compatible and 24 malformed records plus subprocess and bridge event forwarding. No test entry points or CI configuration were changed. Cross-platform results are recorded by the release workflow.
