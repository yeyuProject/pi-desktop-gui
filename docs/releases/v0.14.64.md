# Pi Desktop v0.14.64

- Reduce streaming overhead by sending changed content blocks and text suffixes, limiting live tool previews, refreshing hidden windows less often and saving running state less frequently. Final messages, usage and approvals still update promptly.
- Track changed files between commands in large projects, bound checkpoint caches and postpone cleanup until the app is idle. Uncertain file tracking still triggers a full scan.
- Reuse completed conversation calculations, fix Markdown caching for square brackets, save drafts after a short pause and load larger dialogs on demand. Switching chats and quitting wait for pending draft saves.
- Explain disabled send buttons and environment checks, keep pending approvals within reach and distinguish completed and failed chats in the sidebar. Improve recovery actions and settings feedback.
- Clarify project permissions and per-chat send behavior. Keep a temporary copy before restoring a conversation tree, with an undo action during the current app run. Offer an optional, cancelable restart countdown after tasks finish.
- Replace raw system errors with actionable messages, retain technical details in diagnostics and standardize common interface wording with an automated copy check.

Windows validation, requirement coverage and scoped performance measurements are recorded in [the optimization test report](https://github.com/yeyuProject/pi-desktop-gui/blob/v0.14.64/docs/testing/optimization-prd.md).

## 中文

- 降低流式输出开销：只传变化的内容块和新增文字，限制运行中工具预览，隐藏窗口减少刷新，运行状态减少写盘。最终回复、用量和审批仍及时更新。
- 大项目在命令之间跟踪变动文件，限制检查点缓存，等应用空闲后再清理；无法确认文件变化时仍完整扫描。
- 长对话复用已完成的计算，修复方括号使 Markdown 缓存失效的问题。草稿停止输入片刻后保存，较大的弹层按需加载；切换会话、退出前等待草稿保存完成。
- 发送按钮不能点击时说明原因，环境检查提供具体处理动作，待审批内容可以直接定位，侧栏区分完成和失败。补充崩溃后的操作和设置保存提示。
- 说明项目权限和各会话的发送方式。恢复对话树前保留临时副本，本次应用运行期间可还原；可选择任务完成后自动重启更新，倒计时可以取消。
- 系统报错改成用户能处理的提示，技术细节保留在诊断中；统一高频界面用词，新增文案检查。

Windows 验证、需求完成情况和限定场景下的性能测量见[优化测试记录](https://github.com/yeyuProject/pi-desktop-gui/blob/v0.14.64/docs/testing/optimization-prd.md)。
