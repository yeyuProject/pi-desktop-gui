# Pi Desktop v0.14.53

- Replace Goal text widgets with a compact status bar, expandable Markdown evidence and a result jump. Completed Goals collapse after eight seconds and restore as a dot after switching or restarting.
- Create a Goal in one dialog with an optional advanced usage limit: unlimited, 500k, 2m, 5m or custom. Adjust an exhausted limit and resume without clearing the objective or cumulative usage.
- Count CJK text, side history and the new question in Side Chat's shared half-window budget; preview omitted turns and keep that count with saved history. Preserve existing side histories, projects and quoted chips when continuing in a new chat.
- Stop side answers before deletion confirmation, distinguish side-only answers during exit/update, allow idle process release and abort the Pi-side request when the bridge times out.
- Keep three-digit turn numbers visible, use the theme's running color, restore folds after closing search and show feedback when a turn has no reply to copy.
- Fold long quotes by displayed height, support quoting live tool and shell output, and place the selection menu below text when the top edge has no room.

## 中文

- Goal 改为一行状态条，详情按需展开，证据以 Markdown 显示，并可跳到对话中的结果。完成后 8 秒收起为圆点，切换或重启后也以圆点恢复。
- 新建 Goal 使用单个对话框，用量上限放在可选的高级项中，支持不限、500k、2m、5m 和自定义；用尽后可调整并继续，保留目标和累计用量。
- 侧边对话按中文占用计算主会话摘录、侧边历史和新问题的共同预算；提前显示省略轮次，并随历史保存。旧记录继续可读，作为新会话继续时保留项目和引用芯片。
- 删除会话前先停止侧边回答；退出或更新时单独提示，侧边回答不会阻止空闲进程释放；桥接超时也会停止 Pi 侧请求。
- 轮次序号支持三位及以上，运行刻度使用主题颜色；关闭查找后恢复原来的折叠状态，没有回复可复制时显示提示。
- 长段引用按显示高度折叠，运行中的工具输出和命令输出也可引用；顶部空间不足时，选区菜单显示在文字下方。
