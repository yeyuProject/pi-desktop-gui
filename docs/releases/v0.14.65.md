# Pi Desktop v0.14.65

- Fix user messages wrapping before using the available space. Keep bubbles within 80% of the conversation column and 620px, with tighter padding and line spacing in Classic, Codex and Claude appearances.
- Move user message actions below the bubble. Show them on hover or keyboard focus, keep their order consistent and offer full-content copying only when it differs from regular copying.
- Restore specific model connection test errors for invalid credentials, connection failures and busy services, with redacted diagnostic details available to copy.
- Correct saved-settings feedback, restart-after-task timing, external-editor draft saves, live tool output after expansion and automatic titles for older chats.
- Remove the ineffective crash recheck action and explain the steps needed to continue. Restrictions remain while earlier commands may still be running; restarting the app alone does not end them.
- Clean up orphaned restore backups after a crash, limit active file refresh notifications to once every two seconds and release old conversation arrays from incremental caches.

The earlier PF3 target of reducing 5,000-message renderer updates to one third of the baseline is still unmet. Process tracking after a Pi crash remains deferred. Validation and measurements: [optimization review](https://github.com/yeyuProject/pi-desktop-gui/blob/v0.14.65/docs/testing/optimization-prd.md), [user bubbles](https://github.com/yeyuProject/pi-desktop-gui/blob/v0.14.65/docs/testing/user-bubble.md).

## 中文

- 修复用户提问有空间也提前换行的问题。经典、Codex、Claude 三套外观都保留对话列 80% 和 620px 上限，调整气泡内边距和行高。
- 操作按钮移到气泡下方，悬停或键盘聚焦时显示，统一顺序；只有普通复制与完整内容不同时，才提供「复制完整内容」。
- 测试模型连接时恢复凭据错误、连接失败、服务繁忙等具体原因，可复制隐藏敏感信息后的报错详情。
- 修复设置保存失败仍显示「已保存」、空闲时误触发自动重启、外部编辑器读取旧草稿、工具展开后输出停更，以及旧会话不能自动起标题的问题。
- 去掉无效的崩溃「重新检查」按钮，说明结束残留命令后再重启应用的处理步骤。无法确认命令结束时，继续保留重连和撤销限制；仅重启应用不会结束这些命令。
- 空闲时清理崩溃遗留的恢复副本，运行中的文件变化提醒最多每两秒一次；修复增量缓存持有旧消息数组的问题。

原 PF3 的 5,000 条消息更新耗时降至基线三分之一的目标仍未达到；崩溃后的命令进程记录另行设计。验证范围和测量结果见[优化复查记录](https://github.com/yeyuProject/pi-desktop-gui/blob/v0.14.65/docs/testing/optimization-prd.md)和[用户气泡测试记录](https://github.com/yeyuProject/pi-desktop-gui/blob/v0.14.65/docs/testing/user-bubble.md)。
