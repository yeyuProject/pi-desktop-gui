# Goal G3 输入框交互验证

日期：2026-10-29。版本：v0.14.55；基线 v0.14.54。macOS 本地验证使用锁定的 Pi 1.4.0、本机模型桩、隔离数据与假凭据，没有请求付费模型，也没有修改日常 Pi 数据。

## 覆盖结果

- 输入框内新建/编辑、共用预算浮层、完成后的新建与查看结果两个入口；无 Goal 专用模态框。
- 离线进入 Goal、切换会话与刷新恢复预算和草稿；命令预览、手写预算与芯片同步、Esc 退出保留目标正文。
- 真实 Pi 一次发送文件、超过 4000 字的片段、对话引用与 PNG 图片；只产生一条用户消息和一次完成请求，Goal 状态只保存短目标与文件路径。历史重读和 UI 重载后均显示 Goal 标记。
- 无效文件、存储失败、停止、模型不支持图片、替换取消时不发送；发送期间新的文字或预算不被旧发送快照消费。
- 编辑缓冲区和完整普通草稿分别保存，切换会话及重载后保留；保存/取消恢复普通草稿和材料；旧 revision 保存被拒绝且文字保留。
- 连续修改运行中目标时，下次模型请求只使用最新版本；编辑记录不留下完成后的额外请求。模拟写入失败不会提交新内存 Goal。
- 继续覆盖 G2 的 30 次自动续跑、混合工具调用拒绝、暂停恢复、预算收尾、额度不足、计划、结果跳转、旧版状态和重启后暂停。
