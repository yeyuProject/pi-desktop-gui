# UI20 玻璃材质验收

2026-11-25，Windows 10 LTSC 19044，Electron 44.7.0。使用 `main` 上的 UI18–UI20 集成工作区构建，窗口内容区为 1280 × 820。处理器为 Intel Core i5-13500HX，接通电源。正常启动时 Chromium 报告 GPU 合成为 `enabled`，实际渲染设备是 Intel UHD Graphics，使用 ANGLE Direct3D 11，驱动版本 32.0.101.7088。

## 优化前首轮性能测量

运行 `npm run test:performance-ui -- --glass`。四次独立启动使用相同的 5000 条本地会话消息，分别连续滚动 10 秒、以正常的渲染进程 IPC 接收 30 秒流式更新（300 次），再空闲 30 秒。每约 500 ms 读取 `app.getAppMetrics()`，按实际采样时长加权后合计主进程、当前窗口渲染进程和 GPU 进程的 CPU。帧间隔取前两段实际 `requestAnimationFrame` 的 p95，空闲阶段不采帧。

| GPU 合成 | 请求材质 | 实际材质 | 滚动 CPU | 流式 CPU | 活动 CPU | 空闲 CPU |  活动 p95 |
| -------- | -------- | -------- | -------: | -------: | -------: | -------: | --------: |
| 开启     | 实色     | 实色     |   5.956% |   2.480% |   3.349% |   0.096% | 16.800 ms |
| 开启     | 玻璃     | 玻璃     |   5.639% |   3.647% |   4.146% |   0.115% | 16.800 ms |
| 禁用     | 实色     | 实色     |   4.144% |   2.126% |   2.631% |   0.085% | 16.734 ms |
| 禁用     | 玻璃     | 实色     |   4.331% |   2.069% |   2.635% |   0.062% | 16.800 ms |

| PRD 验收项                                               |       实测差值 |       上限 | 结果     |
| -------------------------------------------------------- | -------------: | ---------: | -------- |
| 开启玻璃后的活动 CPU 增幅                                |     **23.79%** |        15% | **超出** |
| 开启玻璃后的活动 p95 增量                                |        0.00 ms |       2 ms | 通过     |
| 开启玻璃后的空闲 CPU 差值                                | 0.019 个百分点 | 1 个百分点 | 通过     |
| 两组均使用 `--disable-gpu-compositing` 时的活动 CPU 差值 |         0.135% |         5% | 通过     |

活动 CPU 增量主要出现在流式阶段，该阶段的 CPU 从 2.480% 升到 3.647%。关闭 GPU 合成时，实际状态为 `disabled_software`，仍选中玻璃时侧栏计算样式的模糊值为 `none`。本轮为真实硬件测量，脚本因活动 CPU 超出预算返回退出码 1。

首轮原始 JSON 已独立保存在 Windows 系统临时目录的 `pi-glass-ui20-initial-1b48e5c3b091466aa580a576e8f57c65.json`。SHA-256 为 `dcce79f1b59df2e42050d83474f952cf5e6563e76aefcf2d1d773106cbb1556a`。后续运行可通过 `PI_PERF_RESULT` 将结果写入另一个文件。

## 优化后性能复测

玻璃材质下，固定渐变背景 `.app-backdrop` 增加 `will-change: transform`，提示 Chromium 将其单独合成。对话滚动区 `.thread` 增加 `contain: paint`，把滚动和流式输出引起的重绘限制在对话区。复测沿用首轮的测试方式，正常启动确认玻璃模糊生效，关闭 GPU 合成后确认实际显示实色。

| GPU 合成 | 请求材质 | 实际材质 | 滚动 CPU | 流式 CPU | 活动 CPU | 空闲 CPU |  活动 p95 |
| -------- | -------- | -------- | -------: | -------: | -------: | -------: | --------: |
| 开启     | 实色     | 实色     |   5.210% |   1.914% |   2.738% |   0.068% | 16.800 ms |
| 开启     | 玻璃     | 玻璃     |   4.159% |   2.235% |   2.717% |   0.060% | 16.800 ms |
| 禁用     | 实色     | 实色     |   3.631% |   1.781% |   2.244% |   0.054% | 16.800 ms |
| 禁用     | 玻璃     | 实色     |   3.785% |   1.814% |   2.307% |   0.058% | 16.800 ms |

| PRD 验收项                                               |       实测差值 |       上限 | 结果 |
| -------------------------------------------------------- | -------------: | ---------: | ---- |
| 开启玻璃后的活动 CPU 增幅                                |         −0.77% |        15% | 通过 |
| 开启玻璃后的活动 p95 增量                                |        0.00 ms |       2 ms | 通过 |
| 开启玻璃后的空闲 CPU 差值                                | 0.007 个百分点 | 1 个百分点 | 通过 |
| 两组均使用 `--disable-gpu-compositing` 时的活动 CPU 差值 |         2.827% |         5% | 通过 |

四项预算均通过，脚本退出码为 0。原始结果在 `test-results/glass-performance-contained.json`，SHA-256 为 `0cb74c7035b0d1fc9912f4953b55cad1c335392446234fc3f51bb9cb6986ca17`。

## 功能验收入口

性能优化后的功能验收也已通过。材质即时切换，重启保留设置，同时最多 5 个模糊层。拖动侧栏时关闭全部模糊，松手后约 165 ms 恢复。浅色和系统浅色最低对比度为 5.327∶1，深色和系统深色为 4.897∶1。GPU 合成不可用、系统降低透明度和电池供电均触发实色并显示原因。

- `node --import tsx scripts/test-glass-ui.mjs` 运行功能验收，结果与截图写入 `test-results/glass-ui/`。GPU 与电池状态用测试数据注入，降低透明度由 Chromium 的媒体查询模拟。
- `node --import tsx scripts/test-glass-ui.mjs --screenshots-only` 用 24 轮固定数据直接截图，浅色和深色分别写入 `test-results/glass-screenshots/`。两个入口均可用 `PI_GLASS_UI_OUTPUT` 指定输出目录。
