# v0.14.40 审查后续修复

复核基线为 v0.14.39。已在该版本修复的审批、更新签名、回滚、数据清理和交互问题不重复改动。本轮处理剩余缺陷；国际化按用户决定单独安排。

| 复核项目 | 修复与边界 |
| --- | --- |
| 安装和更新资源包 | 主进程先显示来源、作用范围和 npm 安装脚本/扩展的执行风险，默认取消；取消不执行命令、不清空来源。Pi 1.1.0 的更新会覆盖个人及当前工作目录中 Pi 已信任的项目配置，更新不传入不支持的 `--local`。 |
| 仅改大小写的重命名 | 在本机不区分大小写的卷上复现；按真实文件路径找回基线身份，恢复内容和原文件名，不把唯一文件移入回收站。父目录大小写变化在任何写入前拒绝，避免移动未选择的同级文件。 |
| 撤销范围截断 | 保留现有文件数和深度上限，同时记录并展示所有超限路径或未遍历子树；不再静默丢弃每个目录第 1000 项之后的文件。旧快照无法证明未记录文件是新建文件，因此不会自动删除这些文件。 |
| 撤销中途失败 | 明确列出已完成数量及文件、当前文件可能已部分改变、剩余文件未处理；主进程无论成功失败都刷新工作区，检查点界面重新读取清单。 |
| 分支草稿与队列恢复 | 共用附件块解析器；分支不带展开文件正文。队列记录原始输入、引用、粘贴片段和图片，并跟踪 Pi 提前返回的模板展开文本；停止及 Pi 进程崩溃后恢复原始输入，容量不足时生成恢复会话。 |
| BOM 与损坏配置 | 读取忽略 UTF-8 BOM。无效 JSON 返回可编辑原文、文件路径和密钥提示；修复保存仍执行锁、版本检查和备份。原文包含的密钥不会被谎称已经隐藏。 |
| 对话全量同步 | 完整普通轮次保留事件增量数据；压缩、导航、恢复和不完整事件流仍重新读取对话。统计数据继续刷新。 |
| 检查点缓存 | 哈希缓存按会话及项目根目录隔离，最多保留八个会话；切换回来不重复存储未变文件，清理会话同时清理缓存。 |
| 平台与安全细节 | 扩展常见凭据及自定义字段脱敏；打开目录前验证类型；缺少 Bash 仍提示未就绪；Windows Python 使用 UTF-8；终端正常退出执行清理锁的 trap；删除未使用的桥接写配置入口。 |
| 工程检查 | 增加 ESLint、CI 格式检查及过期分支/PR 运行取消，LF 由 Git 属性与 Prettier 约束。lint 独立工作区使用其解析器支持的 TypeScript，应用继续使用 TypeScript 7；安装包排除开发检查工具。 |

## 明确限制

后台服务如果已经脱离 Pi 的进程跟踪，停止/退出不能承诺结束它；停止、强制结束和退出文案已说明需要手动释放端口。UTF-8 环境变量适用于 Python，无法修复所有强制输出 GBK 的第三方程序。错误脱敏覆盖已知格式及凭据字段，不能识别任意没有格式线索的秘密文本。跨平台安装与更新最终结果以同一提交的 Windows/macOS/Linux CI 和发布资产验证为准。
