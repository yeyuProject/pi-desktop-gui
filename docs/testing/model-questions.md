# Q1 模型反问验收

实现版本：v0.14.61。生产环境的 Goal 等待上限为 10 分钟，普通任务没有超时。

## 覆盖范围

| PRD 要求 | 验证方式 |
| --- | --- |
| 问题和回答格式 | `tests/ask.test.ts` 覆盖数量、长度、重复标识和选项、推荐项、伪造选项、单选多答、其他回答及原型属性名；主进程拒绝非法回答后保留原问题 |
| 同一回合继续与计划保留 | `scripts/test-ask.ts` 驱动真实 Pi，比较回答前后的用户消息数量与计划，并核对模型实际收到的工具结果 |
| 普通等待、Goal 超时与次数上限 | 普通问题没有 `expiresAt`；真实 Goal 使用隔离测试桥接包把 600000 毫秒缩为 150 毫秒，验证推荐答案、保持 active、自动续跑及下一轮重置次数。生产代码没有测试环境变量入口 |
| 停止与超时同时发生 | 单测验证过期问题仍可明确取消；扩展收到取消结果时不会生成推荐答案。真实 Pi 停止流程验证 `cancelled` 已写入历史 |
| 单选、多选、其他、补充说明 | 真实 Electron 界面检查单题立即提交、多题未答完时按钮禁用、字段原文回传，以及推荐项显示 |
| 键盘和焦点 | 验证方向键只移动焦点、数字键和 Space 选择、Tab 到下一题、Ctrl/⌘+Enter 提交；关闭文字框后焦点仍在面板，第二次 Esc 打开跳过确认；面板外双击 Esc 停止当前任务 |
| 输入框代答与草稿保护 | 文件、图片、片段、引用分别被拒绝且草稿保留；纯文字回答第一题，其余题跳过；`/goal` 和 `@` 开头的文字不会触发其他操作；编辑 Goal 不会提交问题回答 |
| 切换会话、结束及删除 | 多选和说明在切换后恢复；`RuntimeStore` 清理已结束问题及被移除会话的草稿，过期界面事件不能重新写回旧草稿 |
| 历史、查找、复制 | 真实 Pi 离线读取仍有问答详情；界面查找问题正文、选中答案和说明；复制按钮将完整问题与答案交给既有复制接口 |
| 等待状态和通知 | 真实界面进入 waiting；后台问题的通知包含会话名、第一题标签和正文；关闭 `notifyOnApproval` 后不发送通知 |
| Goal 与普通计划共存 | 问题替换普通计划卡，回答后原计划恢复；Goal 卡位于问题上方并显示倒计时，回答后 Goal 继续 active |
| 外观与长内容 | 经典、Codex、Claude 的浅深色截图；三道长问题、六个长选项、窄窗口和 150% 缩放下内部滚动，面板不超过对话区一半，提交按钮保持可见，无横向溢出；“回到最新”位于回答面板上方，不覆盖回答操作 |
| 只读和第三方扩展 | 三种审批模式均放行提问；真实只读会话不弹审批；原有 `test-features-ui.mjs` 中的第三方扩展界面流程保持通过 |

## 本机验证

Windows、Node.js 22.23.1、仓库锁定的 Pi 1.4.0。

- `npm run build`、`npm run lint`、`npm run format:check`、`git diff --check` 通过。
- 全量 `npm test`：794 项，786 通过，8 项平台跳过，无失败。
- `npm run test:integration` 通过，包含原有集成及新的真实 Pi 提问流程。
- `npm run test:goal` 通过，覆盖原有续跑、完成、暂停恢复、用量上限、额度不足和运行中修改目标。
- `node --import tsx scripts/test-features-ui.mjs` 通过。
- `node --import tsx scripts/test-ask-ui.mjs` 通过，截图位于 `test-results/ask-*.png`，README 使用 `docs/assets/screenshots/ask-panel.png`。
- `npm run screenshots` 已重新生成并检查现有外观预览。

新增界面测试核对传给 `clipboard.writeText` 的问答内容，并执行原有写入。本机独立 Electron 小程序写入固定探测文本后也只能读回空字符串，因此这里不声称已经验证本机系统剪贴板的完整读回。应用的剪贴板实现没有改动；现有聊天和原生主题测试仍保留实际读回检查，由 CI 继续运行。
