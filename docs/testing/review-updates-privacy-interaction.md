# 更新、数据与日常交互复核

复核基线：v0.14.38，本地分支 `codex/review-update-privacy-interaction`。上一轮 1–4 的审批边界修复已存在。本轮核查和修改 16–26，并补上先前未修改的 5–6。修复纳入 v0.14.39；本地验收使用隔离安装包，不修改用户正在使用的安装。

| 项目 | 复核结论与修复 |
| --- | --- |
| 16 更新身份 | 原来的散列来自同一发布来源，不能证明发布者身份；“6 小时内所有用户都会安装”过于绝对，还取决于退出、联网和安装类型。现在先验内置公钥的 Ed25519 签名，再解析清单和校验安装包。默认手动下载，退出不安装；CI 只生成待独立签名的草稿 Release。 |
| 17 mac 启动失败 | 原来只在换包后的完整性检查失败时回滚。现在新版本须在 60 秒内完成索引和工作界面初始化并回传随机挑战，提前退出或超时会先停止本次新进程，再恢复旧包和重新启动。无法确认进程退出时保留备份，避免替换运行中的程序。 |
| 18 大会话 | 64 MiB 文件级限制确实存在，Pi 压缩会追加记录，不能靠它保证缩小磁盘文件。现在大文件逐行建立偏移索引，只加载当前分支；预览最多 16 MiB，并显示限制提示。原始文件及完整用量统计保留；单条记录仍有 128 MiB 防护。 |
| 19 保存恢复 | 原来一次失败后必须重启。现在运行期写盘失败每 5 秒重试，界面也有“重试保存”。成功落盘后才解除只读；格式不兼容、损坏索引和图片校验失败不自动解除保护。 |
| 20 删除与隐私 | 删除会话同时清理专属检查点对象、桥接脚本、临时草稿，并从轮换/升级备份中移除该会话草稿，回收无人引用的草稿图片。新增带范围说明及二次确认的“清除桌面本地数据”入口。外部项目、Pi 外部历史、供应商凭据不在清除范围内；原会话文件仍按原交互进入回收站。 |
| 21 更新网络 | 更新代理、HTTPS 镜像可单独设置，镜像仍必须通过相同公钥验证。无显式代理时使用进程继承的 HTTPS_PROXY / ALL_PROXY，之后才回退系统代理。直接读取发布资产，更新检查不再依赖 GitHub API 额度。 |
| 22 待审批提醒 | 前台窗口只抑制正在查看的会话通知，其他会话仍可提醒。增加全局待回复入口、Dock 数字角标和 Windows 任务栏覆盖图标，侧栏收起仍可进入待回复会话。 |
| 23 键盘审批 | 保留输入焦点；⌘/Ctrl+Shift+A 首次定位允许按钮，审核后再按一次才允许。⌘/Ctrl+Shift+D 进入拒绝原因，Enter 确认拒绝。输入法组合输入和模态弹窗不会触发批准。 |
| 24 变更审查 | 增加逐文件审查及 Alt+PageUp/PageDown、改动段导航及 Alt+[ / ]。大段按 100 行分组跳过不可见布局，保留现有后台计算、取消、过期结果保护和差异追问。 |
| 25 对比度 | 明确定义各主题的 warning 颜色。实测五种主题文字与侧栏背景对比度分别约 6.66、5.77、5.27、10.33、10.88，均大于 4.5。 |
| 26 小项 | 保存窗口缩放，固定 px 字号跟随字号比例，快速切换加入操作搜索，完成/审批/错误通知分别设置，面向用户的连接报错提供可执行的恢复步骤。 |
| 5–6 启动检测 | shell 读取失败不再永久缓存；关闭其标准输入，显式重新检测允许重试，短期自动查询共享冷却时间。补上 Homebrew、nvm、fnm、Volta、pnpm 常见目录，解析 npm 链接后使用所选 Node。 |

## 验证

- 全量单元测试：`node --import tsx --test --test-concurrency=2 --test-timeout=120000 tests/*.test.ts tests/*.test.mjs`。结果：651 通过、0 失败、2 项平台跳过；最后的更新定向测试也通过。证据：`test-results/review-unit-full.log`、`test-results/review-final-targeted.log`。
- `npm run build` 与 TypeScript 检查通过。
- 真实 Pi 审批界面：后台会话、收起侧栏、Dock 角标、键盘批准/拒绝、中文草稿保留、只读手动命令保护通过。证据：`test-results/review-approval-ui.log`。
- 差异界面：大文件计算期间仍可操作、切换取消、草稿保留、文件及改动段导航、对照、外部修改过期提示和追问通过。证据：`test-results/review-diff-ui.log`。
- 设置界面：操作搜索、网络设置保存、独立通知开关、取消数据清除、主题对比度和缩放重启恢复通过。证据：`test-results/review-ui.json`。
- macOS arm64 真实安装包往返：篡改清单被拒、正常更新、初始化失败自动回滚、退出不安装通过。证据：`test-results/update-roundtrip.json`。使用独立应用身份、安装目录、数据目录与临时公钥，不碰正式安装。

本机只执行了 macOS 安装包验证，Windows/Linux 安装器仍需在各自 CI 环境运行现有往返测试。待确认样式改善及分块布局有实际界面验证，不承诺所有硬件或所有差异尺寸的性能。

## 发布前必读

参见 [独立更新签名](../update-signing.md)。私钥在仓库/CI 外的本机受限目录，尚未迁至离线介质；此状态不能称为已离线保管。正式发布前需独立核验安装包，生成三份签名并随草稿发布。旧客户端需要先升级到包含验签逻辑的可信版本。
