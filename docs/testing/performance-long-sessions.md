## 实现范围

- `LfJsonDecoder` 只扫描新到达的字符串块，到换行时才拼接完整 JSON；保留 UTF-8、CRLF、无效记录和未完成记录大小限制的处理。
- 轮次统计复用工具补丁的增删行数；补丁替换、清空及工具状态晚到仍重新计算相应结果。仍会遍历消息元数据，没有另建一套持久化索引。
- 搜索按消息缓存文本和当前查询的数值位置，只为当前查看的命中生成摘要。全部命中仍可访问，不按数量截断。
- 轮次或搜索跳转使用最多 80 条消息的页面，并提供前后翻页与“回到最新”。工具和重试分组仅挂载当前页消息，摘要保留完整数量并标明本页数量。用户主动从末尾连续“加载更早”仍会累积展开历史。

## 持续验证

- `npm run test:performance-core`：真实生产解码器、历史差异统计、密集搜索；写入 `test-results/performance-core.json`。CI 在三个系统执行。
- `npm run test:performance-ui`：生产构建的 Electron 页面，验证 5000 条历史首尾跳转、翻页、搜索循环和重载后回到末页；写入 `test-results/performance-ui.json`。
- 新增 5000 条消息、1250 份各 500 行历史差异的界面样本。本机 30 次流式更新中位数 14.0 ms、P95 17.5 ms，观察期无超过 50 ms 的任务。界面计时包含测试 IPC、React 更新与下一动画帧，不能与纯函数计时直接相加。
- 单元测试覆盖大记录分块、大小限制、缓存失效、全部命中可访问、分组跨页及思考内容边界。`npm test` 在隔离模型凭据环境变量后通过 601 项，7 项按平台条件跳过。真实 Pi 集成、滚动跟随、会话交互、历史恢复和重试界面均已验证。

本机继承的供应商 API 环境变量会使模型目录测试多出可用模型；本次只在测试子进程中移除了这些变量，未修改个人配置或生产行为。模型与工具集成测试使用本地验收接口。
