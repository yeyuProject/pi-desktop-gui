## 实现范围

- `LfJsonDecoder` 只扫描新到达的字符串块，到换行时才拼接完整 JSON；保留 UTF-8、CRLF、无效记录和未完成记录大小限制的处理。
- 轮次统计复用工具补丁的增删行数；补丁替换、清空及工具状态晚到仍重新计算相应结果。仍会遍历消息元数据，没有另建一套持久化索引。
- 搜索按消息缓存文本和当前查询的数值位置，只为当前查看的命中生成摘要。全部命中仍可访问，不按数量截断。
- 轮次或搜索跳转使用最多 80 条消息的页面，并提供前后翻页与“回到最新”。工具和重试分组仅挂载当前页消息，摘要保留完整数量并标明本页数量。用户主动从末尾连续“加载更早”仍会累积展开历史。

## 2026-10-24 差异预览与折叠工具卡改进

基线为 `cd04607`，Apple Silicon macOS 本机，Node 26.8.1、Electron 44.7.0。
使用生产构建和隔离合成数据，没有调用模型或读取个人会话。

本轮围绕打开编程会话、展开工具结果、回看差异、输入草稿和快速切换文件验证：

- 折叠工具卡保留摘要，首次展开、搜索命中、运行中或错误状态才挂载正文；关闭后释放正文。再次展开恢复差异或输出区域的内部滚动位置，复制仍返回完整工具输出。
- 文件差异在独立 Node worker 中计算，完整文件展开与较大补丁的行对齐在 Web Worker 中计算。切换文件、项目或标签页会取消旧预览；请求编号避免旧取消操作影响新文件，结果身份检查避免旧内容覆盖当前预览。
- 差异算法最多计算 5 秒，worker 的整体等待上限为 8 秒。超时或失败显示明确提示，保留在编辑器中查看的入口。正常差异仍保留原来的上下文、中文路径、无结尾换行标记和 256 KiB 截断提示。

相同的 5000 条消息、1250 份各 500 行补丁、末页 20 个折叠工具卡样本，补丁包含真实的 `@@` hunk 头。每种状态测量两次：

| 全页面元素数量 | 46670 | 1290 |
| 渲染器 GC 后 JS 堆 | 50.6–50.7 MiB | 38.3 MiB |
| 重载到内容出现后的下一帧 | 280–356 ms | 142–154 ms |
