# 界面用词

| 内容 | 统一叫法 |
| --- | --- |
| 一次 Pi 工作 | 会话；保留产品名“独立对话”“侧边对话” |
| 可撤销的一轮文件备份 | 检查点 |
| 撤销文件修改、授权 | 撤销；备份恢复叫“从备份恢复” |
| 结束正在运行的任务 | 停止；未开始的连接或登录用“取消” |
| 添加的文件夹 | 项目 |
| 右侧文件和差异面板 | 变更面板 |
| 运行命令所在目录 | 工作目录 |
| 模型推理设置 | 推理级别 |
| 桌面与 Pi 之间的扩展 | Pi Desktop 的配套扩展 |
| 本地保存的数据 | 会话列表数据、本地数据、保存 |
| 发起团队任务的会话 | 负责人 |
| 接收独立子任务的会话 | 成员 |
| 一次工具调用分出的一组任务 | 分派 |
| Markdown 与 YAML 定义的成员能力和提示 | 角色 |
| 对话流中的成员进度与汇报卡 | 团队卡 |
| 输入框上方的团队摘要 | 团队条 |

错误先说明原因和下一步。退出码、英文异常和开发细节放入诊断。
